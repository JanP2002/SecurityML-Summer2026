1. Experiment Overview & Goals

Step 2 extends the closed-world baseline (Step 1) into an open-world setting: can a model trained on n known attack types detect an unseen attack type n+1?

The experiment has two components, run by two separate scripts:

step2.py — AnomalyCNN Baseline

Progressive multi-attack curriculum training using the standard AnomalyCNN architecture (3 conv layers, max-pool, binary output). Tests on both MNIST (6 attacks) and Pythia (8 attacks). Includes order-sensitivity analysis and MNIST variant robustness checks.

Seed: RANDOM_SEED = 42 · NUM_PERMUTATIONS = 4

step2_professor.py — ProfessorCNN Suite MAIN DELIVERABLE

ProfessorCNN-based reproducibility suite for Pythia. Directly addresses Prof. Tałataj's request: systematically compare different attack selection strategies. Adds seeded repeats, full training sets, and a pairwise protocol.

Seed: BASE_SEED = 2137 · RUN_REPEATS = 5

The central research question, as stated by Prof. Tałataj:

"Chodzi o eksperymentowanie z różnymi strategiami wyboru typów ataków ze zbioru Pythia. Na przykład samo A, możemy porównać z połączeniem A, B, E."
Translation: "Experiment with different attack type selection strategies for Pythia. For example, just A, compare with combination A, B, E."

2. Baseline: AnomalyCNN Progressive Training

Protocol: At round n, the model is trained from scratch on:

  • Clean data (all available clean samples)
  • Balanced subset from each of A₁,…,Aₙ (downsampled to match clean set size, maintaining 1:1 ratio)

Then evaluated on clean_test ∪ Aₙ₊₁ (the next unseen attack). AnomalyCNN hyperparameters: 15 epochs, patience=3, batch=64, BCELoss, Adam.

2.3 Order Sensitivity Analysis

The key finding from order sensitivity: on MNIST, specific orderings matter — e.g., training on Blended first and testing on OOD second works far better than the reverse, because Blended introduces useful texture features. On Pythia, ordering is irrelevant because no ordering can create a useful feature representation with this architecture.

3. Why ProfessorCNN?

After the AnomalyCNN baseline produced uniformly random results on Pythia, we introduced ProfessorCNN — the architecture selected via hyperparameter grid search (step_professor_search.py, results in faza_professor_cnn_search.json).

ProfessorCNN — Architecture Overview

ProfessorCNN is the best architecture found by the grid search over channel widths, kernel sizes, depth, dropout rates, and learning rates. Compared to AnomalyCNN:

AnomalyCNN (baseline)

  • 3 conv layers, fixed 3×3 kernels
  • Max-pooling after each conv
  • 15 epochs, patience = 3
  • BCELoss + Adam, lr = 0.001
  • No dropout
  • ~15K trainable parameters

ProfessorCNN (selected by search)

  • Deeper conv stack, wider channels
  • Spatial pooling preserved but more stages
  • 200 epochs, patience = 20 (much longer)
  • BCELoss + AdamW, tuned lr
  • Dropout regularisation
  • AUC-ROC monitored early stopping
  • ~100K–300K trainable parameters

The longer training (200 epochs vs. 15) and AUC-monitored early stopping are critical — AnomalyCNN's 15-epoch cap was likely causing premature convergence to the degenerate solutions. ProfessorCNN has more capacity to potentially find the subtle Pythia signal.

However, a critical problem was identified: When run in the AnomalyCNN framework's training loop, ProfessorCNN results were extremely variable run-to-run — sometimes worse than AnomalyCNN, sometimes marginally better. Investigation showed two root causes:
  1. Downsampling: balanced_attack_subset() cut training data to match clean set size (1:1 ratio), leaving only ~100–150 attack samples — far too few for ProfessorCNN's parameter count.
  2. No fixed seed: different random initialisations produced wildly different final models.
These issues were addressed in step2_professor.py.

4. Reproducibility Improvements (step2_professor.py)

Four concrete improvements were implemented to make the ProfessorCNN experiment reliable and fair:

Improvement 1

Deterministic Seeding

set_global_seed(seed) seeds Python random, NumPy, PyTorch CPU/CUDA, and sets cudnn.deterministic=True. Every experiment can be exactly reproduced by re-running with the same seed.

Improvement 2

5 Seeded Repeats

RUN_REPEATS = 5 with seeds BASE_SEED + 0..4 per subset. Results reported as mean ± std. This quantifies variance and ensures a single lucky/unlucky init doesn't dominate the result.

Improvement 3

Full Training Set

Removed the balanced_attack_subset() downsampling. ProfessorCNN uses all available attack samples (≈640 per attack after 80/20 split). This gives the model a fighting chance to learn the signal.

Improvement 4

Pairwise Protocol

Step 1-style: for each of 56 ordered pairs (train on X, test on Y, X≠Y), 5 repeats each. Directly comparable to Step 1 methodology. Total: 280 training runs.

Hyperparameters

BASE_SEED      = 2137
RUN_REPEATS    = 5
TRAIN_EPOCHS   = 200
TRAIN_PATIENCE = 20
BATCH_SIZE     = 64
Monitor        = AUC-ROC

7. Failure Analysis: Why Pythia Doesn't Generalise

7.1 The signal exists — architecture can't access it

A diagnostic ceiling analysis using logistic regression on raw pixel features (_ceiling.py) showed AUC = 0.845. The attack signal is present in the pixel values — it is just very localised. CNN with spatial max-pooling aggregates over spatial locations, destroying exactly the local perturbation information that Pythia attacks encode.

7.2 Mode collapse anatomy

With only ~640 clean and ~640 attack samples per training run, and a model with 100K–300K parameters, ProfessorCNN finds two pathological optima that minimise binary cross-entropy without learning the signal:

Mode A: Always-attack
Output logit → always high. BCE loss is minimised at 50% accuracy (equal clean/attack ratio). Recall = 1.0, Precision = 0.5, AUC depends on score distribution randomness (≈0.5). Observed in 4 of 5 seeds for most subsets at n ≥ 2.
Mode B: Always-clean
Output logit → always low. Same 50% accuracy. Recall = 0, Precision = undefined, AUC ≈ 0.45–0.48. Observed sporadically at n=1 (high seed variance) and round n=6 of AnomalyCNN progressive.

The fact that n=1 (A only) has F1 std = 0.33 (randomly flips between modes) while n≥2 has F1 std ≈ 0 (locks into mode A) suggests: the larger multi-attack training set consistently drives the model to Mode A — but adding diversity does not break out of it.

  1. AnomalyCNN baseline is broken on Pythia. It produces degenerate always-attack or always-clean classifiers across all 7 progressive rounds and all orderings. F1 = 0.667 is not a good result — it reflects the always-attack mode in a 1:1 balanced test set.
  2. ProfessorCNN with all improvements also fails on Pythia. With full training data, 200 epochs, and 5 seeded repeats, ProfessorCNN achieves mean AUC = 0.48–0.51 across all 9 subsets and all 56 pairwise evaluations. This is statistically indistinguishable from random.
  3. The choice of attack subset does not matter. A+B+E (diverse, professor's suggestion) vs. A+B+C (sequential) vs. A+D+G (spread) all produce nearly identical AUC values within ±0.02 of each other. Increasing n from 1 to 6 shows no monotonic improvement. The hypothesis that diverse attack selection improves generalisation is refuted for this architecture on this dataset.
  4. The negative result is reproducible. 5-seed repeats show std AUC ≈ 0.010–0.025 — the variance is small enough that the result is not a sampling artefact. Every seed converges to the same conclusion.
  5. The bottleneck is architectural. Spatial max-pooling destroys the localised perturbation signal. The solution requires an architecture without aggressive spatial pooling (e.g., fully-convolutional, ViT patch attention, or GBM on pixel features — which already achieves AUC = 0.61 from Step 1).
Answer to Professor Tałataj's question: We compared 9 attack selection strategies for Pythia using ProfessorCNN with 5-seed reproducibility. The directly tested A+B+E achieves mean AUC = 0.490, compared to A only (0.498) and A+B+C (0.491). All differences are within noise. The answer is: for CNN-based anomaly detectors, the selection strategy for Pythia attacks has no significant effect on generalisation — the failure is architectural, not curriculum-dependent.
